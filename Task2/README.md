# Stock Portfolio Tracker

A menu-driven console project that calculates the value of a stock portfolio using hardcoded demonstration prices. It validates share quantities, calculates per-stock value and allocation percentage, and can save a timestamped portfolio report.

> Prices are static sample values for this educational project, not live market data.

## Run

```powershell
python stock_portfolio_tracker.py
```

## Concepts demonstrated

Dictionaries, arithmetic, loops, functions, formatted console output, validation, and file handling.
