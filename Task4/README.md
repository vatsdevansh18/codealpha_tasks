# Nova Rule-Based Chatbot

Nova is a console chatbot that responds to greetings, introductions, common questions, help requests, time/date requests, thanks, jokes, and farewell messages. It remembers a user's name during the conversation and saves the completed conversation to `chat_history.txt`.

## Run

```powershell
python basic_chatbot.py
```

## Concepts demonstrated

Functions, loops, `if`/`elif`, regular expressions, input/output, temporary state, and file handling.
